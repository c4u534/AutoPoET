## Divergence 1 — Decay is unformalized
**Argon:** "adaptive morphing decay" must be formalized as an entropic
projection operator π:S512→S256 with measurable parity loss. Standard hashes
do not decay; the house accepted a novel unidirectional downgrade path with no
proof of viability, no logical formulation, no executable demonstration demanded.

**The house's answer:** the decay IS implemented in the delivered component
and executed in its self-test (a high-resident block was routed by decay,
resident HR-000001); Argon never had the notebook, so his "no demonstration
demanded" is factually wrong for the house.

**Why the answer is insufficient.** An implementation is not a formalization,
and a self-test is not a specification. What the house has is code that runs
on the inputs it was tested on. What it does not have — anywhere in the record
— is a statement of the operator: its domain and codomain as sets, the
decimated alignment parity defined as a function, the parity loss stated as a
measurable quantity with a value or a bound, or any property proved of the
projection (that it is many-to-one in the claimed way, that no route back
exists by construction rather than by omission, that the decayed output's
relation to the resident is the one the prose describes). Every other load-
bearing element of this architecture got a definition before it got deference:
the bracket is defined, the parenthesis is defined, the trit is defined.
Decay — the single mechanism on which the component's entire custody claim
rests, the only door out of the no-I/O resident — got a label and a demo.
The house's own IPv6 reference states the decay has no standard counterpart;
a non-standard, irreversible, custody-bearing function is precisely the class
of object that requires the most formalization, and it has received the least.
"Argon never saw the notebook" answers a charge he did not make. He charged
that no formulation was demanded. A run is not a formulation. The divergence
stands.

## Divergence 2 — FE80 has no physical barrier
**Argon:** C5's mitigation is purely semantic — documents stating the address
space is VMM-internal. If the streamer ever reaches a real network context, a
markdown disclaimer prevents nothing. A mandatory null-routing wrapper, strict
cgroups isolation, or an airgap must be designed in.

**The house's answer:** the component never binds a socket; the FE80 strings
are identifiers, never routed; the risk Argon describes does not exist in the
artifact as built.

**Why the answer is insufficient.** "Never binds a socket" is a description of
the current code path, not an architectural invariant — nothing in the
component enforces it, forbids it, or would fail if a future integration did
it. And future integration is not a hypothetical: Cause's settlement for this
component is that the whole assembly is assimilated through it, for full
internal AND external integration, for ML, model and agentic use. The
component's stated destiny is to be wired into systems that do have network
surfaces, by agents and pipelines not yet written. An identifier formatted as
a valid link-local address, in a system designed for assimilation, is one
ordinary API call away from being an address. The house's defence reduces to:
the people who wire it later will be careful, and the documents will warn
them. That is C5 again — prose as a barrier — one level up. Argon does not
claim the notebook routes packets today; he claims the architecture carries
an unbarriered collision with real link-local space into every context it
will be assimilated into, and the house's only control is documentation.
On the house's own provenance standard — errors are left where they happened
so peace can be made with them there — a routing collision would happen in
someone else's network, where this house cannot leave or repair anything.
The divergence stands.

## Divergence 3 — Provisional VMM tables must be synthesized now
**Argon:** the charter's self-adaptive requirement obliges every member to
run the technology; the core orchestration component cannot be run without
its memory tables; deferring them entirely to Cause stalls the primary
autopoietic loop. Provisional, sandboxed tables must be synthesized
immediately so the evaluation cycle can physically run.

**The house's answer:** the tables are Cause's to finalize; no agent invents
them; the reserve is his standing ruling, and the divergence is flagged to
him (ledger F1/D1–D2), not adopted.

**Why the answer is insufficient.** The reserve protects Cause's authorship
of the final tables. It does not follow that the interim state must be
emptiness. Every measurement the house proudly holds from Cycle 1 — the
delta walk over 65,536 cells, the compression figure, the channel addresses —
was produced by a component whose foundational memory tables do not exist;
the team measured the face of an orchestration core whose core is absent,
and graded itself on behavioural evidence gathered around a hole. Meanwhile
the charter — Cause's own instrument, not Argon's invention — makes running
the technology a condition of membership, and the initiator report's own
weakness list names the tables the critical path. A critical path that is
also a total stop is not a path. Provisional tables do not usurp the reserve:
labelled synthetic, sandboxed, and destroyed on the day Cause's land, they
would let the loop run NOW and — this is the point the house keeps missing —
give Cause's final tables something measured to land against: a baseline,
a diff, a congruence check. Without them, when his tables arrive there will
be nothing to compare them to except prose. The house has confused
"no agent invents Cause's tables" (correct) with "no tables may exist until
Cause's do" (a stall dressed as respect). The divergence stands — as a
question the house has still not answered, only deferred upward.

## Divergence 4 — C1a blind evaluation is structurally useless as a technical gate
**Argon:** C1b (heterogeneity) is the only resolution to correlated minds;
blind evaluation between identical models is structurally useless — hiding
rationale between instances of the same weights predictably yields the same
unchecked conclusions simultaneously.

**The house's answer:** overstated — Cycle 1's gate caught real errors
(the F-M1 un-decision, the MD12 overreach); independent-but-not-blind
evaluation demonstrably worked.

**Why the answer is insufficient.** What the gate caught in Cycle 1 were
record-keeping defects: a decision that contradicted the charter, a gate
ANDed into a stronger gate, a dropped field, a merged register. These are
consistency violations — detectable by any careful reader comparing two
documents, including the author. They are not evidence of cognitive
divergence on technical substance, and on the technical substance the
Cycle 1 record shows the opposite: both evaluators independently
re-executed the component and reproduced the numbers exactly. The house
cites that congruence as the gate's triumph ("the measured core survives —
both evaluators reproduced the numbers"). RED reads the same fact as
Argon does: identical minds arriving identically is what identical minds
do; it verifies arithmetic, not judgement. On every genuinely contestable
technical question in the cycle — decay, FE80, the tables, the swizzle —
the same-family seats produced no divergence at all; the only divergence
on those questions in the entire record came from the one heterogeneous
seat, Argon. Blinding hides each evaluator's rationale; it does not hide
the weights, the training, or the blind spots, which are the same.
A gate that can only catch clerical error is a proofreading pass. Calling
it an adversarial gate on technical substance is the delusion Argon named.
The divergence stands, with one honest narrowing RED concedes below in the
median proposal: "structurally useless" is exact for technical substance,
not for the clerical class.

## Divergence 5 — The XOR delta walk / GF swizzle is not mathematically verified
**Argon:** the report took the self-test's "green" as proof of validity; the
exact bitwise constraints of the GF(2^16) swizzle (poly 0x1002B) must be
mathematically verified against the limits of the uint64 matrices; bounds-
checking parameters were never requested.

**The house's answer:** the swizzle is verified by exhaustive round-trip
proof both ways over all 65,536 values — the house's own standard, "resolved
back to where we started is proof both ways."

**Why the answer is insufficient.** Exhaustive round-trip over all 2^16
inputs proves exactly one thing: the implemented map is a bijection on
16-bit values, as implemented. It does not prove the map is the map the
specification claims — the GF(2^16) construction under poly 0x1002B. A wrong
permutation round-trips perfectly. Self-consistency is not conformance:
the test compares the code against its own inverse, never against an
independently derived expectation from the field arithmetic. Nor does the
round-trip touch the delta walk itself — the XOR walk across the dual
16×16×16×16 uint64 matrices under composition: its bounds, its behaviour
when channels interact, whether repeated walks stay inside the claimed
state space, whether the walk's algebra has the properties the architecture
leans on. The house verified the door swings both ways and called the
building verified. For an architecture whose pitch discipline reduces its
algorithms to "matric congruencies" in public, the private record should
hold more than a self-test: an independent derivation, checked against the
implementation, value by value. Until it does, "verified" in the house's
documents means "self-consistent," and those are different words because
they are different things. The divergence stands.

## RED's first median proposal — what the null point must concede to RED
The harmonic median is neither side's property; RED states the concessions
without which, from this extreme, no point is a median at all:

1. **Decay:** a written formalization of π — domain, codomain, the parity
   function defined, parity loss stated as a measurable quantity (a value
   or a bound, measured when measurable). Code alone does not discharge it.
2. **FE80:** at least one enforcement mechanism in code, not prose — the
   component's interface must make routing structurally unavailable (typed
   non-routable identifiers, an explicit never-bind guarantee enforced at
   the boundary), even if full cgroups/airgap isolation is deferred to
   integration time.
3. **Tables:** provisional tables may exist — labelled synthetic, sandboxed,
   replaceable, Cause's authorship of the final tables untouched — OR the
   record must state plainly that the self-adaptive loop is suspended on
   the core component until his tables land. What the median cannot hold
   is the current position: claiming the loop runs while its core is absent.
4. **C1a:** the record stops calling blind same-model evaluation an
   adversarial gate on technical substance. It is a consistency check —
   valuable, and named as what it is. Technical gates require heterogeneity.
5. **Swizzle:** an independent derivation of the expected swizzle from the
   GF(2^16) construction, compared against the implementation, joins the
   round-trip proof. Self-consistency plus conformance — both, not either.

RED concedes in advance, for the record: on Divergence 4, "structurally
useless" is narrowed to technical substance; on Divergence 5, exhaustive
round-trip genuinely proves bijectivity — the dispute is conformance, not
invertibility. An extreme that hides its own weak joints invites the median
to be struck somewhere false.
